# Источники и лицензии

Курс опирается на открытые библиотеки и данные. Их лицензии сохраняются, тексты лицензий лежат рядом с файлами.

| Что | Где в репозитории | Источник | Лицензия |
|---|---|---|---|
| Hanzi Writer 3.7.3: анимация черт и проверка рисования | `vendor/hanzi-writer/` | [chanind/hanzi-writer](https://github.com/chanind/hanzi-writer), автор David Chanin | MIT, текст в `vendor/hanzi-writer/LICENSE` |
| Контуры и порядок черт | `data/hanzi/` | [hanzi-writer-data 2.0.1](https://github.com/chanind/hanzi-writer-data), данные проекта [Make Me a Hanzi](https://github.com/skishore/makemeahanzi), извлеченные из шрифтов Arphic Technology | Arphic Public License, текст в `data/hanzi/ARPHICPL.TXT` |
| Записи слогов | `data/audio/syl/` | [hugolpz/audio-cmn](https://github.com/hugolpz/audio-cmn), диктор Chen Wang | CC BY-SA |
| Записи слов HSK | `data/audio/word/` | [hugolpz/audio-cmn](https://github.com/hugolpz/audio-cmn), диктор Yue Tan, записи сделаны в SWAC Recorder | CC BY-SA |

Записи audio-cmn используются без изменений. Слова, для которых записи нет, озвучивает синтезатор речи браузера.

Тексты уроков, карточки иероглифов и код курса написаны для этого репозитория.

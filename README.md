# Китайский с нуля

Курс для самостоятельного изучения китайского языка. Этап 1 «Основы»: тоны и звуки, черты и порядок их написания, устройство иероглифов, первые слова и фразы. 13 уроков, 61 иероглиф.

**Курс онлайн:** https://temeka1221.github.io/chinese_lang_edu/

## Что внутри

- **Тренажер черт** в четырех режимах: «По шагам» (каждая черта отдельно, со стрелкой направления и названием), «Целиком» (анимация), «Обводка» (по красному контуру) и «По памяти». Рисовать можно мышью, пальцем или стилусом.
- **Карточки иероглифов**: несколько ассоциаций для памяти, звуковая зацепка для чтения, настоящая история знака, как писать, что не перепутать, слова с озвучкой.
- **Уроки по одной схеме**: цели, разминка по прошлым урокам, теория с аналогиями, мини-проверки, новые знаки, практика, итог. В разговорных уроках практика включает фразы: собрать из слов, вставить пропущенное слово, понять на слух.
- **Повторение** по коробкам Лейтнера: знаки пройденных уроков и слова, составленные из изученных знаков (новые слова приходят не больше десяти в день). **Словарь** с поиском по знаку, пиньиню и значению.
- **Панель урока**: оглавление с текущим разделом, возврат к месту, где остановилось чтение, и кнопки, которые скрывают пиньинь и перевод в списках слов.
- **Задания на слух**: «какой знак звучит» в практике и слова на слух в повторении.
- **Прописи**: страница `sheets.html` собирает лист A4 для письма от руки по знакам урока или по своему набору.
- **Работа без сети**: курс ставится на телефон как приложение, а кнопка на главной сохраняет все страницы, данные и записи на устройстве.
- **Звук**: записи носителей для слогов и слов. Если записи нет, слово читает синтезатор речи браузера, а без китайского голоса — записи слогов по очереди. Два третьих тона подряд при этом звучат как второй и третий, а вместо легкого тона, которого в записях почти нет, звучит тот же слог с другим тоном.

## Запуск на своем компьютере

Сайт статический, сборка не нужна. Модули JavaScript не загружаются с диска напрямую, поэтому курс открывается через любой локальный веб-сервер. Из корня репозитория:

```bash
python3 -m http.server 8000
```

После запуска курс доступен по адресу http://localhost:8000. Подходит и встроенный сервер GoLand: index.html открывается в браузере прямо из IDE.

## Работа без сети

Служебный воркер `sw.js` кладет в кэш все, что открывалось, и отдает это, когда сети нет. Страницы, код и данные при наличии сети всегда берутся свежими, записи и контуры черт — из кэша. Кнопка «Сохранить курс на устройстве» на главной скачивает все файлы из `offline.json` (около 5 МБ), после этого копия обновляется сама раз в день. Список `offline.json` пересобирается при каждом запуске `tools/fetch_data.py`, поэтому после добавления файлов скрипт запускается заново.

## Прогресс

Прогресс хранится в localStorage браузера и привязан к адресу сайта. На главной странице есть кнопки «Сохранить в файл» и «Загрузить из файла»: файл переносит прогресс на другое устройство или на новый адрес курса и служит резервной копией.

## Устройство репозитория

```
├── index.html, review.html, dictionary.html, sheets.html   главная, повторение, словарь, прописи
├── lessons/          уроки 00–12
├── css/course.css    стили, светлая и темная тема
├── js/               тренажер, упражнения, прогресс, звук, общий код страниц
├── data/
│   ├── course.json         модули и уроки
│   ├── chars.json          иероглифы: черты, ассоциации, история, слова
│   ├── stroke-types.json   справочник типов черт
│   ├── hanzi/              контуры черт по знакам
│   └── audio/              записи слогов и слов, index.json — список записей
├── vendor/hanzi-writer/    библиотека Hanzi Writer
├── sw.js, manifest.webmanifest, icons/   работа без сети и установка на телефон
├── offline.json            список файлов для копии на устройстве, его пишет fetch_data.py
├── tools/fetch_data.py     скачивание контуров и записей, проверки данных
└── tests/                  тесты логики в браузере
```

## Как добавить урок или иероглиф

1. В `data/course.json` добавляется урок: id, файл, название, минуты, описание.
2. В `data/chars.json` добавляются иероглифы с полем `lesson`: пиньинь, значение, названия черт по порядку, ключ, тип, ассоциации, звуковая зацепка, история, слова. Пиньинь записывается по обычной орфографии: `rénkǒu`, `yí ge rén`, `Xī'ān`.
3. Файл урока в `lessons/` строится по образцу соседних (разметка ниже).
4. `python3 tools/fetch_data.py` скачивает контуры черт и записи для новых знаков и проверяет данные: число черт и их направление, слоги в словах, наличие записей для упражнений на слух. При ошибке скрипт завершается с кодом 1. Адреса, которых нет в источниках, запоминаются в `tools/missing.json` и при следующем запуске не запрашиваются; ключ `--refresh` проверяет их заново.
5. Тесты логики открываются по адресу `/tests/` и показывают итог PASS или FAIL.

### Разметка уроков

| Разметка | Что появляется |
|---|---|
| `<div data-cards></div>` | карточки иероглифов урока |
| `<div data-strokes="永"></div>` | отдельный тренажер черт |
| `<div data-stroke-types="basic"></div>` | справочник черт: `basic` или `compound` |
| `<span data-frames="十"></span>` | лента порядка черт прямо в тексте |
| `<ul data-words><li data-hz="大人" data-py="dàrén">взрослый</li></ul>` | слова с пиньинем и озвучкой |
| `<div class="check" data-answer="2">…</div>` | мини-проверка с пояснением в `.why` |
| `<div data-exercises="meaning char pinyin order write"></div>` | практика по знакам урока |
| `data-from="earlier"`, `data-from="all"` | разминка по прошлым урокам, тест по всем знакам |
| `data-exercises="… hear …"` | в практике по знакам: звучит знак, нужно выбрать его среди созвучных |
| `data-exercises="tone" data-syllables="ma1 ma2"` | тоны на слух |
| `data-exercises="sound" data-sets="ba1/pa1 ji1/qi1/xi1"` | звуки на слух |
| `<div data-exercises="build gap listen"><ul hidden><li data-hz="我没有姐姐。" data-py="Wǒ méiyǒu jiějie." data-gap="没有 不有 不是">У меня нет старшей сестры.</li></ul></div>` | задания на фразы: собрать из слов, вставить слово, понять на слух |
| `<button class="say" data-say="ma1">mā</button>` | кнопка звука: слог, слово или цепочка через пробел |
| `<aside class="note analogy">` | врезка: `analogy`, `trap`, `history`, `rule`, `culture` |
| `<span class="py">nǐ hǎo</span>` | пиньинь в цветах тонов |

Фраза в заданиях делится на плитки по словам пиньиня, поэтому пиньинь пишется по словам, а знаков и слогов в нем поровну. В `data-gap` первым стоит верное слово, за ним неверные варианты. `data-tiles="三 百 六 十 五"` задает свое деление на плитки, когда они нужны мельче слов.

Любой иероглиф в тексте урока автоматически открывает свой порядок черт по клику.
